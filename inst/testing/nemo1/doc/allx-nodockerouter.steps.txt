4b. ./mynemo-mitigation-init-container.sh: run ./mynemo-mitigation-init-vsmd-certs.sh in order to create the nemo inter detection/mitigation communication certs + adapt vsmd config accordingly

4c. ./mynemo-mitigation-init-container.sh : build nemo mitigation container + run it + inside do all further necessary installations and starting of proccesses ... also run checks internally as appropriately [covers: vsmd, offrampctl, exabgp + exabgp plugin, ssh jump host + mitigation stats fetch script on jump host, everything with appropriately stichted config to interact internally (netween these compoennts) and externally to appropriate nemo detection container and freertr for BGP and ssh/telnet traffic]

4d ./mynemo-mitigation-init-container.sh : ./mynemo-detection-restart-mitigated: fix connectivity (hosts file) in appropriate nemo detection container and restart the nemo detection container which connects to vsmd, verify that connection is actually established
